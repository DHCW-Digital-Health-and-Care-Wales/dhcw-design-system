When to use the dashboard

Use the dashboard for staff who use health and care systems as part of their work. It supports task-based workflows and movement between related areas of a service.

For public-facing services, use the top navigation templates instead. See page templates.

How to use the dashboard

Group related links in the left-hand navigation. Each group is separated by a divider. Mark the current page with aria-current="page".

Use the top bar to show where the user is working, who they are signed in as, and a way to exit.

Accessibility

Give the left-hand navigation an accessible name, such as "Service navigation". Navigation icons are decorative and hidden from screen readers, so every link must have visible text.
