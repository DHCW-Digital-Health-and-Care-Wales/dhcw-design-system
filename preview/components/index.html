All DHCW components

Components are reusable parts of a user interface that have been made to support a variety of applications. Individual components can be used in multiple different pages, patterns and context.

  • Action link

    Use buttons to help users carry out an action on a page like starting an application or saving their progress.

    View the 'Action link' documentation

  • Back link

    Use back links to help users go back to the previous page in a multi-page transaction.

    View the 'Back link' documentation

  • Breadcrumbs

    Use breadcrumbs to help users understand where they are in the website.

    View the 'Breadcrumbs' documentation

  • Buttons

    Use buttons to help users carry out an action on a page like starting an application or saving their progress.

    View the 'Buttons' documentation

  • Checkboxes

    Use checkboxes to let users select 1 or more options on a form.

    View the 'Checkboxes' documentation

  • Callouts

    Use a warning callout to help users identify very important content on the page, even if they do not read the whole page.

    View the 'Callouts' documentation

  • Cards

    Use a card to visually group related content and actions to help users do what they need to more quickly.

    View the 'Cards' documentation

  • Expander

    Make a complex topic easier to digest by letting users reveal more detailed information only if they need it.

    View the 'Expander' documentation

  • Details

    Make a page easier to scan by letting users reveal more detailed information only if they need it.

    View the 'Details' documentation

  • Date input

    Use date input to help users enter a memorable date, like their date of birth.

    View the 'Date input' documentation

  • Error summary

    Include an error summary at the top of a page to summarise any mistakes a user has made.

    View the 'Error summary' documentation

  • File upload

    Help users select and upload a file.

    View the 'File upload' documentation

  • Footer

    Use the footer to show users they are on an NHS service and to help them find links they expect at the bottom of our pages.

    View the 'Footer' documentation

  • DHCW header

    Use the appropriate header at the top of every page to show users they are on an NHS service and help them get started in finding what they need.

    View the 'Header' documentation

  • Inset text

    Use inset text to help users identify and understand important content on the page, even if they do not read the whole page.

    View the 'Inset text' documentation

  • Notification banners

    Use a notification banner to tell the user something they need to know that's not directly related to the page content.

    View the 'Notification banners' documentation

  • Pagination

    Use pagination to help users navigate forwards and backwards through a series of pages.

    View the 'Pagination' documentation

  • Panel

    The panel component is a visible container used on confirmation or results pages to highlight important content.

    View the 'Panel' documentation

  • Radios

    Use radios when you want users to select only 1 option from a list.

    View the 'Radios' documentation

  • Select

    Use select to let users choose an option from a long list but only use it as a last resort.

    View the 'Select' documentation

  • Site navigation

    Site navigation gives users an overview of a site's content by outlining its main categories. It can also help users find key content.

    View the 'Site navigation' documentation

  • Skip link

    Use the skip link component to help keyboard-only users skip to the start of the content on a page.

    View the 'Skip link' documentation

  • Summary list

    Use the summary list to summarise information, for example, a user's responses at the end of a form.

    View the 'Summary list' documentation

  • Table

    Use a table to make it easier for users to compare and scan information.

    View the 'Table' documentation

  • Tabs

    Use tabs to let users navigate between related sections of content, displaying 1 section at a time.

    View the 'Tabs' documentation

  • Tag

    Use tag to show users the status of something.

    View the 'Tag' documentation

  • Textarea

    Use textarea to let users enter more than 1 line of text.

    View the 'Textarea' documentation

  • Text input

    Use text input to let users enter a single line of text.

    View the 'Text input' documentation

  • Warning text

    Use warning text when you need to warn users about something important, such as legal consequences of an action, or lack of action, that they might take.

    View the 'Warning text' documentation
