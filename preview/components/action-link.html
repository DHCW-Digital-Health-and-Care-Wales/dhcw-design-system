When to use action links

Use action links to signpost the start of a digital service or task. For example, users might need to change an appointment, order a repeat prescription or find a pharmacy.

When not to use action links

Do not use action links in forms. Use a button instead.

Do not use action links to link to another page or site. If you want to draw attention to a link, use inset text.

How to use action links

Keep action link text short. Start with a verb, for example: "Book a blood test" or "Order a repeat prescription".

Action links usually appear within in a block of text. You can also use an action link in a care card.

You can use more than 1 action link on a page, but avoid putting them close together. Leave enough space between action links so users can easily identify and select the right action.

Accessibility

The link colour and background colour contrast ratio is 5.76:1. This passes WCAG 2.2 success criterion 1.4.3 Contrast (Minimum), level AAA guidelines at that font size.

When using an action link on dark backgrounds, make sure all users are able to see the link. The background colour must have a contrast ratio of at least 4.5:1 with white to meet WCAG 2.2 Success Criterion 1.4.3 Contrast (Minimum), level AA (W3C).
