When to use breadcrumbs

Use breadcrumbs when users may need to:

  • understand where they are in the wider website or service
  • navigate between related content
  • move back to a higher-level page to explore other options

When not to use breadcrumbs

Do not use breadcrumbs in transactional journeys.

They can distract users from completing their task and encourage them to leave the journey before they have finished.

How to use breadcrumbs

If the full breadcrumb trail does not fit on one line, allow it to wrap onto two lines. Keep each breadcrumb link on the same line.

Do not include the current page in the breadcrumb trail. The page heading already tells users where they are.

On smaller screens, replace the full breadcrumb trail with a "Back to [parent page]" link.

Add aria-label="breadcrumb" to the nav element so screen reader users can identify the breadcrumb navigation.

Accessibility

Leave space around breadcrumb links. Avoid placing other interactive elements immediately beside them to reduce the risk of users selecting the wrong thing. This supports WCAG 2.2 Success Criterion 2.5.8: Target Size, level AA.

Make sure all users can see the breadcrumbs. The background colour must have a contrast ratio of at least 4.5:1 with white to meet WCAG 2.2 Success Criterion 1.4.3: Contrast (Minimum), level AA

Source

Learn more about Breadcrumbs in the GOV.UK Design System.
