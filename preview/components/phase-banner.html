When to use the phase banner

Use the phase banner when a service is in alpha or beta. It shows users that the service is still being developed and gives them a way to send feedback.

Remove it when the service goes live.

How to use the phase banner

Place the phase banner directly below the site navigation, or inside the header for services that use a dark header.

Name the phase honestly, for example Alpha or Beta, and always link to a place where users can give feedback.

Accessibility

The phase tag is text, so it is announced by screen readers. The tag and text meet the minimum colour contrast ratio of 4.5:1, supporting WCAG 2.2 Success Criterion 1.4.3: Contrast (Minimum), level AA.

Alpha banner in the header

Use the reverse variant inside the dark header. This is the phase banner used by the page templates.
