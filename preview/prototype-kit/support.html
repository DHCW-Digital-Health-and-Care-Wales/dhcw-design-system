If you have a problem using the prototype kit, there are several ways to get help.

Check the guidance

Go back to the guidance you were following and check that you have completed each step.

  • Set up your computer if you’re having problems with GitHub Desktop, Visual Studio Code or Node.js
  • Create a new prototype if you’re setting up or working on a new prototype
  • Work on an existing prototype if someone has shared a prototype with you

If you see an error message, copy it or take a screenshot. This can help someone understand what went wrong.

Ask someone in your team

If you need help with your prototype, ask a developer or someone in your team who has experience using GitHub, Visual Studio Code or Node.js.

Show them the step you were following and any error message you saw.

Contact the Service Desk

Contact the Service Desk if the problem is with your computer or installing software, for example if:

  • you cannot install GitHub Desktop, Visual Studio Code or Node.js
  • Windows asks for an administrator password
  • the software will not install or open

Tell them what you were trying to do and what happened.

Contact the Design System team

Email design.system@wales.nhs.uk if you need help using the prototype kit or its guidance, for example if:

  • the prototype kit does not work as described
  • you’re not sure how to use part of the kit
  • the guidance is unclear or appears to be incorrect

Include the step you were following, what happened and any error message or screenshot.
