What you’ll do

Make your own copy of the prototype kit on GitHub. This is where the prototype will be saved.

Steps

  1. Go to the DHCW prototype kit template. Sign in to GitHub if you’re asked.
  2. Select Use this template, then Create a new repository. A repository is a place on GitHub where the files for the prototype are stored.
  3. Next to Owner, choose DHCW-Digital-Health-and-Care-Wales.
  4. In Repository name, enter a name for the prototype. Use lower case letters and hyphens, and end the name with -prototype. For example manage-vaccinations-in-schools-prototype

What you should see

Your new prototype will open in GitHub. You should see the name you entered at the top of the page.

If something goes wrong

  • If you cannot see Use this template, check you’re signed in to GitHub.
  • If you cannot select the DHCW organisation or create the repository, contact the Design System team.
