What you’ll do

Add more pages and use components from the DHCW Design System to build your prototype.

Add a new page

  1. In Visual Studio Code, use the Explorer to open the src folder, then the app folder, and find the views folder.
  2. Right-click the folder and select New File.
  3. Give the file a name, for example start.html .
  4. Add your content and press Ctrl+S to save.
  5. Open the page in your browser at http://localhost:3000/start .

Add a component

  1. Go to the DHCW design system and find the component you want to use.
  2. Copy the example code.
  3. Paste it into your page in Visual Studio Code.
  4. Press Ctrl+S to save.
  5. Go back to your browser and check the page.

Link pages together

To link to another page, add a link to your page. The address is the file name without .html. For example, this links to start.html:

<a class="nhsw-link" href="/start">Continue</a>

To send people to different pages depending on their answer, you need a form and a small amount of JavaScript. This example asks how to contact someone.

Add the form to a page:

{% raw %}<form method="post" action="/contact">
  {{ nhswRadios({
    name: "contact",
    fieldset: { legend: { text: "How should we contact you?" } },
    items: [
      { value: "email", text: "Email" },
      { value: "phone", text: "Phone" }
    ]
  }) }}
  {{ nhswButton({ text: "Continue", type: "submit", classes: "nhsw-button--primary" }) }}
</form>{% endraw %}

Then open routes.js in the app folder. Add this above the line export default router:

router.post('/contact', (request, response) => {
  if (request.session.data.contact === 'email') {
    response.redirect('/email')
    return
  }

  response.redirect('/phone')
})

Create email.html and phone.html in the views folder. If someone selects Email, they go to the email page. Otherwise they go to the phone page.
