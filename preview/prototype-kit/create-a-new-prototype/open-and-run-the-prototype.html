What you’ll do

Open the prototype in Visual Studio Code and run it, so you can see it in your web browser.

Steps

  1. In GitHub Desktop, select Open in Visual Studio Code.
  2. In Visual Studio Code, select Terminal, then New Terminal.
  3. Check the terminal panel says Command Prompt. If it does not, select the down arrow next to the + icon and choose Command Prompt.
  4. Type npm install and press Enter . Wait for it to finish. This can take a few minutes the first time.
  5. Type npm run dev and press Enter .
  6. When the terminal shows that the prototype is running, open your web browser and go to http://localhost:3000 .
Information:

“Localhost” means the prototype is running on your own computer. Nobody else can see it yet.

What you should see

Your prototype should open in your browser.

Stop the prototype

Keep the terminal open while you’re working on your prototype. When you’ve finished:

  1. Click inside the terminal.
  2. Press Ctrl + C.
  3. If it asks Terminate batch job (Y/N)?, type Y .
  4. Press Enter .

If something goes wrong

  • If you cannot get your prototype running, go to Get help.
