What you’ll do

Change some text on your starter page. This checks everything is working and shows you how changes appear.

Steps

  1. In Visual Studio Code, use the Explorer panel on the left to open the src folder, then the app folder, then the views folder.
  2. Open index.html.
  3. Find the heading Your prototype and change it to your own words.
  4. Press Ctrl + S to save your change.
  5. Go back to your browser. You should see your new text. If you do not, refresh the page.

What you should see

The text you changed should now appear on your prototype.

Information:

Your change is only saved on your computer so far. You’ll save it to GitHub in Step 6: Save the prototype to GitHub.

If something goes wrong

  • If your change does not appear, check that you saved the file. In Visual Studio Code, a dot on the file's tab means there are unsaved changes.
  • If the prototype does not load, check that it is still running in the terminal.
