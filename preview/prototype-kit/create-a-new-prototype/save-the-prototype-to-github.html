What you’ll do

Save your changes to GitHub so they are backed up and other people can access them.

There are 2 parts:

  • first you save your changes with a short description, this is called a commit
  • then you send them to GitHub, this is called a push

Steps

  1. Open GitHub Desktop. The files you’ve changed appear in the Changes list.
  2. In Summary, write a short description of what you changed, for example “Add start page”.
  3. Select Commit to main.
  4. Select Push origin.

What you should see

GitHub Desktop says “No local changes”. The Push origin button changes to Fetch origin.

(SCREENSHOT SHOWING GITHUB DESKTOP AFTER PUSHING)

If something goes wrong

  • If you cannot see any changes, check you saved your files in Visual Studio Code.
  • If you see an error when you commit or push your changes, go to Get help.
