What you’ll do

Copy your prototype from GitHub onto your computer. This is called cloning.

Steps

  1. Open GitHub Desktop.
  2. Select File, then Clone repository.
  3. On the GitHub.com tab, select the prototype from the list.
  4. Check the Local path. This is the folder on your computer where the prototype will be saved. Choose a folder that is not in OneDrive, for example C:\prototypes.
  5. Select Clone.

What you should see

GitHub Desktop shows the prototype’s name at the top left and “No local changes”.

If something goes wrong

  • If you cannot see the prototype in the list, check you created it in step 1 and you’re signed in to the same GitHub account.
  • If GitHub Desktop says the path is too long, choose a shorter folder name, for example C:\prototypes .
