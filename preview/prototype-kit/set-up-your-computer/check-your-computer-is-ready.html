What you’ll do

You’ll use the Terminal in Visual Studio Code to check that the tools you need have installed correctly.

The Terminal lets you give your computer instructions by typing commands. You only need to use the commands shown in this guide.

You do not need to understand the commands or use the Terminal for anything else at this point.

Steps

  1. Open Visual Studio Code from the Start menu.
  2. Select Terminal from the top menu, then New Terminal. A panel opens at the bottom of the window. If you cannot see Terminal, select the three dots (…) to show more menu options.
  3. In the terminal panel, select the down arrow next to the + icon and choose Command Prompt.
  4. Type node --version and press Enter . You should see a version number that starts with ‘v’.
  5. Type npm --version and press Enter . You should see another version number.
  6. Open GitHub Desktop. Check you’re still signed in.

You’re ready if

  • You can sign in to GitHub
  • GitHub Desktop opens and shows your account
  • Visual Studio Code opens
  • node --version and npm --version both show a version number

If something goes wrong

If you see “node is not recognized as an internal or external command”:

  1. Close Visual Studio Code.
  2. Restart your computer.
  3. Open Visual Studio Code and try node --version again.

If you still see the message, reinstall Node.js, then try again.
