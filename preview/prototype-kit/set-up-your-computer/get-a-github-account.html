Information:

Set up your computer before you use the prototype kit for the first time. You only need to do this once.

What you’ll do

Create a GitHub account using your work email address. You’ll use GitHub to save your prototypes and work on prototypes with other people.

If you already have a GitHub account, go to Step 2: Install GitHub Desktop.

Steps

  1. Go to github.com.
  2. Select Sign up.
  3. Enter your work email address, create a password and choose a username.
  4. Follow the instructions to verify your account. GitHub will send a code to your email address.
  5. If you’re asked to choose a plan, choose the free plan.

What you should see

You should be signed in to GitHub and see your username.

If something goes wrong

  • If you do not receive the verification email, check your junk folder and try sending the code again.
  • If your username is already taken, choose a different one.
