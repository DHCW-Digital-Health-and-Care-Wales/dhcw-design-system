What you’ll do

Install Visual Studio Code (also known as VS Code). You’ll use it to open and change the files that make up the prototype.

Steps

  1. Go to code.visualstudio.com.
  2. Select Download for Windows.
  3. Open the downloaded file from your Downloads folder in File Explorer.
  4. Accept the licence agreement and select Next.
  5. On the Select Additional Tasks screen, select both Open with Code options. This makes it easier to open your prototype in Visual Studio Code later.
  6. Select Next, then Install.
  7. Select Finish.

What you should see

Visual Studio Code open on a Welcome tab.

If something goes wrong

If Windows asks for an administrator password, contact your local Service Desk and tell them you need to install Visual Studio Code.
