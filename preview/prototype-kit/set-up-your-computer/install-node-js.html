What you’ll do

Install Node.js. It lets your computer run the prototype kit, so you can see the prototype in a web browser.

Steps

  1. Go to nodejs.org.
  2. Download the LTS version for Windows.
  3. Open the downloaded file from your Downloads folder.
  4. Accept the licence agreement, then select Next. Keep the default settings.
  5. If you see an option to automatically install the necessary tools, leave it unticked.
  6. Select Install, then Finish.
  7. Restart your computer. This helps Windows recognise Node.js.

What you should see

Nothing yet. You’ll check that Node.js installed correctly in the next step.

If something goes wrong

If Windows asks for an administrator password, contact your organisation’s Service Desk and tell them you need to install Node.js.
