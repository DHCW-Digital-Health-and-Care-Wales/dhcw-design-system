What you’ll do

Install GitHub Desktop. You’ll use it to get prototypes onto your computer and to save your changes.

Steps

  1. Go to desktop.github.com.
  2. Select Download for Windows.
  3. Open GitHubDesktopSetup-x64.exe from your Downloads folder.
  4. Wait for GitHub Desktop to install. It will open when it’s ready.
  5. Select Sign in to GitHub.com and follow the instructions to sign in.
  6. If you’re asked to configure Git, check your name and email address are correct, then select Finish.

What you should see

GitHub Desktop open on the Let’s get started screen, with your username shown in the top left.

If something goes wrong

  • If Windows asks for an administrator password, contact your local Service Desk and tell them you need to install GitHub Desktop.
  • If you cannot sign in, check you’ve verified your GitHub account by email.
