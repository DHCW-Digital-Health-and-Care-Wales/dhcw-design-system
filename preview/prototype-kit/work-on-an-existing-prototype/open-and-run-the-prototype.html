What you’ll do

Get the latest version of the prototype and run it on your computer so you can see and make changes.

Steps

  1. If you’ve worked on this prototype before, get the latest changes first. In GitHub Desktop, select Fetch origin. If the button changes to Pull origin, select it. This brings in changes other people have made.
  2. Select Open in Visual Studio Code.
  3. In Visual Studio Code, select Terminal, then New Terminal.
  4. Check the terminal panel says Command Prompt. If it does not, select the down arrow next to the + icon and choose Command Prompt.
  5. Type npm install and press Enter . Wait for it to finish. This can take a few minutes the first time.
  6. Type npm run dev and press Enter .
  7. When the terminal shows that the prototype is running, open your web browser and go to http://localhost:3000 .

What you should see

The prototype should open in your web browser.

Stop the prototype

Keep the terminal open while you’re working on your prototype. When you’ve finished:

  1. Click inside the terminal.
  2. Press Ctrl + C.
  3. If it asks Terminate batch job (Y/N)?, type Y .
  4. Press Enter .

If something goes wrong

  • If you cannot get your prototype running, go to Get help.
