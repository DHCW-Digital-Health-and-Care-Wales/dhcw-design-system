What you’ll do

Make changes to the prototype and check them in your browser.

Before you start

Get the latest version before you make changes:

  1. Open GitHub Desktop.
  2. Select Fetch origin.
  3. If this changes to Pull origin, select it.

This gets any changes other people have made since you last worked on the prototype.

Change a page

  1. In Visual Studio Code, open the page you want to change.
  2. Make your changes.
  3. Press Ctrl+S to save.
  4. Check your changes in the browser.

Add a component

  1. Go to the DHCW design system and find the component you need.
  2. Copy the example code.
  3. Paste it into your page in Visual Studio Code.
  4. Press Ctrl+S to save.
  5. Check the component in your browser.

Working with other people

Other people may be changing the prototype at the same time. Get the latest changes before you start, and only change the parts of the prototype you're working on.

When you’re ready to save your changes to GitHub, go to Step 6: Save your changes to GitHub.
