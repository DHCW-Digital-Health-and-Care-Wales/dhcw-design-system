What you’ll do

Save your changes to GitHub so they are backed up and other people can access them.

There are 2 parts:

  • first you save your changes with a short description, this is called a commit.
  • then you send them to GitHub, this is called a push.

Steps

  1. Open GitHub Desktop. The files you’ve changed appear in the Changes list.
  2. In Summary, write a short description of what you changed, for example “Add start page”.
  3. Select Commit to main.
  4. If you see Pull origin, select it to get the latest changes before you push.
  5. Select Push origin.

What you should see

GitHub Desktop should show “No local changes”, and Push origin should change to Fetch origin.

If something goes wrong

  • If you cannot see your changes, check that you saved your files in Visual Studio Code.
  • If GitHub Desktop reports a conflict or you cannot push your changes, go to Get help.
