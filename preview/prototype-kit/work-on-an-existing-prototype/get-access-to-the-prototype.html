What you’ll do

Get access to the prototype on GitHub so you can work on it.

Steps

  1. Send your GitHub username to the person who owns the prototype. Set up a GitHub account first if you do not have one.
  2. When they give you access, GitHub will send you an email invitation.
  3. Open the email and select View invitation.
  4. Select Accept invitation.

What you should see

The prototype should open on GitHub, with its name at the top of the page.

[GITHUB SCREENSHOT - prototype page after accepting the invite]

If something goes wrong

  • If you cannot find the invitation, check your junk folder. Then ask the person who invited you to check they used the correct GitHub username.
  • If the invitation has expired, ask them to send you a new one.
  • If you see Page not found, check that you’re signed in to the GitHub account that was invited.
