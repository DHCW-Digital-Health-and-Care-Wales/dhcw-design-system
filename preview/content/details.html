How to find your NHS number

An NHS number is a 10 digit number, like 485 777 3456.

You can find your NHS number by logging in to a GP surgery online service or on any letter the NHS has sent you.

When to use details

The details component is a short link that expands to show more text when a user clicks on it.

Use the component to make a page easier to scan when it contains information that only some users will need. For example, use it to give users help in context.

There are 2 ways to let users reveal more information:

  • details
  • expander

When not to use details

Do not use details to hide information that most users will need.

How to use details

Make the link text short and descriptive so users can quickly work out if they need to click on it.

Details and expanders

Both the details and expander components hide content that users can choose to reveal.

The details component is less visually prominent and is best suited to supplementary information. Use an expander when the content is more important or likely to be needed.

Avoid using the details component in forms. Users may be reluctant to click on it, which could cause them to miss information needed to complete their task.

Accessibility

Make sure all users can see the details. The background colour must have a contrast ratio of at least 4.5:1 with white to meet WCAG 2.2 Success Criterion 1.4.3 Contrast (Minimum), level AA.

Use descriptive summary link text that clearly sets expectations about the hidden content. Avoid vague phrases such as "More information" or "Read more". Instead, use specific text like "How to find your NHS number" so users can understand where the link will take them. This supports WCAG 2.2 Success Criterion 2.4.4 Link Purpose (In Context), level A.

This example shows a page from the School-age Immunisations service where an administrator is reviewing a new child record before final submission. It uses the details component under the introductory text ("How to resolve potential duplicate records in the future") to allow the user to reveal more information if they need it without overloading the page with content.
