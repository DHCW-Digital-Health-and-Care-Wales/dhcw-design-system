When to use site navigation

Use site navigation to provide access to the main sections of a service. It helps users find what they need quickly.

Site navigation helps users move between key areas of a service and provides an overview of its structure.

To decide when to use navigation links in your service, see the Help users to navigate a service pattern in the GOV.UK Design System.

When not to use site navigation

If your service is a linear end-to-end journey, you probably do not need navigation links. You can use the Complete multiple tasks pattern in the NHS England Design System.

How to use site navigation

Site navigation is a set of links that acts as the main navigation for a website or service. It appears consistently across pages and provides access to the main sections of the service.

Place site navigation at the top of the page. On smaller screens it is hidden, unless you use the overflow menu variant, which keeps it available as an expandable menu button.

Place links to your most important top-level sections first. With the overflow menu variant, when there is not enough space to show all links, they are moved into the "More" drop-down list.

Highlight the section the user is currently viewing to help them understand where they are within the service.

Accessibility

Do not allow expanded menus to cover focused content. Avoid fixed or sticky elements that obscure the currently focused element or its focus indicator. Keyboard users must be able to see where focus is at all times. This supports WCAG 2.2 Success Criterion 2.4.11 Focus Not Obscured (Minimum), level AA.

Make sure assistive technologies can identify the list of links as a structural roadmap. The element must use a semantic HTML <nav> or a navigation ARIA landmark role to ensure screen readers can announce the block correctly to meet WCAG 2.2 Success Criterion 1.3.1 Info and Relationships, level A.

Source

Learn more about Site navigation in the GOV.Scot Design System.

Site navigation with an overflow menu

By default, site navigation is hidden on small screens. Use the overflow menu variant when users still need the navigation on a small screen, or when they zoom in. Links that do not fit move into a "More" menu, and the "More" button only appears when it is needed.

Make your browser window narrower to see links move into the menu.

This variant needs the nhsw-behaviours.js script, which works out which links fit and moves the rest into the menu. Without it, the links wrap onto more lines and the "More" button stays hidden.

Users can open the menu with the keyboard, and close it with the Escape key. An open menu pushes the content below it down instead of covering it.
