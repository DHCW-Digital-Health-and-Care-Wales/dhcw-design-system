When to use expanders

The expander is a short link in a box that expands into more detailed text when a user clicks on it. It can help to make complex information easier to understand by allowing users to reveal additional details when they need it.

There are 2 ways to let users reveal more information:

  • details
  • expander

You can use expanders:

  • on pages where users find the amount of information overwhelming, as they help to break down information into bite size pieces which the user can "expand" when they're ready to do so
  • for information for a wide audience, unlike the details component
  • when you see a clear user need for them

Test your content without an expander first. It may be better to:

  • simplify and reduce the amount of content
  • split the content across multiple pages
  • keep the content on a single page, separated by headings
  • use a list of links to let users navigate quickly to specific sections of content

When not to use expanders

Do not use an expander:

  • if only some of your users will need the information – use details instead
  • in forms – instead, add hint text as a part of other form inputs, such as text inputs, radios and checkboxes or use details
  • on pages with other interactive elements, such as buttons or text input – there's a risk that expanders will distract users
  • inside other patterns, for example to help users decide when and where to get care (care cards)

How to use expanders

Make the link text short and descriptive so users can quickly work out if they need to click on it.

Accessibility

The box border outline and the plus/minus toggle icon must have a contrast ratio of at least 3:1 against their background to meet WCAG 2.2 Success Criterion 1.4.11 Non-Text Contrast, level AA.

Make sure assistive technologies accurately announce whether the information panel is open or closed. The toggle button element must dynamically manage state using appropriate structural attributes, such as aria-expanded, to meet WCAG 2.2 Success Criterion 4.1.2 Name, Role, Value, level A.
