Setting up Figma prototypes

Prototype your service using the DHCW Design System's Figma prototyping kit.

If you work for the Digital Healthcare Wales

Use NHS Wales design system components in Figma for rapid wireframing and basic prototyping. We recommend using the prototype kit to build prototypes for usability testing.

Information:

Do not download and use the DHCW Design System from the Figma Community.

How to check that the Figma design system library is active in your file

  1. Open any Figma design file in the app or a browser.
  2. Select 'Assets' from the side navigation and then the book icon.
{% include screenshot-placeholder.html text="Figma Assets panel with the book icon highlighted" %}
  1. Look under the heading 'Libraries added to this file'. If there's 'DHCW Design System V2', the Figma library is active. You do not need to do anything else.
{% include screenshot-placeholder.html text="Libraries added to this file, showing DHCW Design System V2" %}

What to do if the DHCW Design System does not appear

  1. Go to 'Manage libraries' in the side navigation and select 'Recommended' (it has a light bulb icon).
  2. Hover the item and select the 'Add to file' button.
{% include screenshot-placeholder.html text="Manage libraries panel with Recommended libraries and an Add to file button" %}
  1. To check that the files have been added, select 'This file' in the side navigation. You should now see the DHCW Design System. This means the Figma library is active. You do not need to do anything else.

How to get updates from the Figma library

When the Figma library is updated, you'll be notified in Figma. You can also check for updates by:

  1. Going to any Figma design file which has the library activated.
  2. Selecting 'Assets' from the left-hand side panel and then the book icon, or alternatively you can select the book icon at the left corner from the left-hand side panel.
  3. Selecting 'Updates' from the side navigation. This shows a change summary, the author and date, and any 'breaking' changes.
{% include screenshot-placeholder.html text="Updates from DHCW Design System V2 panel with an Update all button" %}
  1. Either selecting the 'Update all' button, or selecting 'Update' for each component you want to update.

Non-Digital Healthcare Wales staff

Use NHS Wales design system components in Figma for rapid wireframing and basic prototyping. We recommend using the prototype kit to build prototypes for usability testing.

How to use the Figma design system library

  1. Find the DHCW Design System library in the Figma community.
  2. Select 'Open in Figma'.
  3. If you have multiple Figma accounts, you'll be asked where you would like to open the file with. Select the account you would like to open it with. The file will now be saved to your profile.
  4. Move the file to the project you're working on so that it can be accessed by everyone working on the project. Read about moving files in Figma.
  5. Publish the file as a library. Read about publishing a library in Figma.

Manually update the DHCW Figma design system

Information:

Since a recent update, Figma no longer allows you to use or reference published shared libraries across completely separate organisations or external user spaces. Therefore, separate corporate organisations or personal external spaces cannot link to each other's live, updating component libraries.

  1. Every so often, check DHCW Design System for updates.
  2. Save a local copy of the latest version of the Figma library.
  3. Reload it into your Figma workspace as a library.
  4. Open your design files, and use the swap libraries feature in Figma to replace all references to the outdated version of the DHCW Figma design system. You can only use 'swap libraries' with a paid Figma licence. If you do not have one, swap components individually instead.
