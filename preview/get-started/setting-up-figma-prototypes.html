Setting up Figma prototypes

Use the DHCW Design System in Figma to quickly create prototypes for your service. There are different ways to access the Design System, depending on whether you work for DHCW.

If you work at DHCW

You can request access to the DHCW Figma workspace and use the shared DHCW Design System library in your design files. This gives you the latest styles and components, ready to drag and drop into your designs.

The User-Centred Design team manages the workspace and can help you choose the right setup for what you need to do. Email dhcw.ucd@wales.nhs.uk to get started.

Information:

We recommend that DHCW staff use the shared library instead of the Figma Community file. This gives you access to the latest Design System updates.

How to add the Design System library

Check the library is active

  1. Open a Figma design file
  2. Select Assets, then select the Libraries icon.
  3. Look under Libraries added to this file. If DHCW Design System V2 appears, the library is active and you do not need to do anything else.

If the library is not active

  1. Go to Manage libraries and select Recommended
  2. Find the DHCW Design System and select Add to file.
  3. Select This file. You should now see the DHCW Design System listed as an active library.

Get updates to the library

Figma will notify you when updates to the library are available. You can also check for updates:

  1. Open a Figma file that uses the DHCW Design System library.
  2. Select Assets, then select the Libraries icon.
  3. Select Updates from the side navigation. This shows a change summary, the author and date and any breaking changes.
  4. Select Update all, or update individual components.

If you work for another organisation

Use the DHCW Design System Community file. It contains components, styles and design assets you can use to mock up NHS Wales digital services in Figma.

You need a Figma account to use the Community file. When you open it, Figma creates a copy of the Design System in your personal workspace. Changes you make to your copy will not affect the original.

How to use the Figma Design System library

Get the Design System

  1. Go to the DHCW Design System in Figma Community.
  2. Select Open in Figma.
  3. Sign in to Figma or create an account if you do not already have one.
  4. If you use more than one Figma account, choose the account you want to use.
  5. Figma will create a copy of the Design System in your drafts.
  6. You can rename or move the file into the Figma project where you are working.

Use the Design System in your designs

Open your copy of the Design System to explore the available components and styles.

You can copy components, such as buttons, form fields and navigation, into your own design files and change their content to suit your service.

Keep your copy up to date

Your Community file is a copy of the Design System. It is not connected to the original DHCW file, so updates we make will not automatically appear in your copy.

Check the DHCW Design System page on Figma Community for newer versions. When a new version is available, open it in Figma to create a new, updated copy.

If you have used your previous copy as a library, you may need to update your existing designs to use components from the newer version.
