Setting up Figma prototypes

Create early prototypes for your service using the DHCW Design System in Figma. There are different ways to access the resources depending on whether you work for DHCW.

If you work for DHCW

If you have access to the DHCW Figma workspace, you can enable the shared DHCW Design System library in your design files. This gives you access to the latest styles and design assets, and lets you drag and drop components straight into your designs.

If you do not have access but think you need it, email dhcw.ucd@wales.nhs.uk for advice.

Information:

If you have access to the DHCW Figma workspace, use the shared library instead of the Figma Community file so you can get the latest Design System updates.

Set up the Design system library

Check the library is active

  1. Open a Figma design file
  2. Select Assets, then select the Libraries icon.
  3. Look under Libraries added to this file. If DHCW Design System V2 appears, the library is active and you do not need to do anything else.

If the library is not active

  1. Go to Manage libraries and select Recommended
  2. Find the DHCW Design System and select Add to file.
  3. Select This file. You should now see the DHCW Design System listed as an active library.

Get updates to the library

Figma will notify you when updates to the library are available. You can also check for updates:

  1. Open a Figma file that uses the DHCW Design System library.
  2. Select Assets, then select the Libraries icon.
  3. Select Updates from the side navigation. This shows a change summary, the author and date and any breaking changes.
  4. Select Update all, or update individual components.

If you don't work for DHCW

Use NHS Wales design system components in Figma for rapid wireframing and basic prototyping. We recommend using the prototype kit to build prototypes for usability testing.

How to use the Figma design system library

  1. Find the DHCW Design System library in the Figma community.
  2. Select 'Open in Figma'.
  3. If you have multiple Figma accounts, you'll be asked where you would like to open the file with. Select the account you would like to open it with. The file will now be saved to your profile.
  4. Move the file to the project you're working on so that it can be accessed by everyone working on the project. Read about moving files in Figma.
  5. Publish the file as a library. Read about publishing a library in Figma.

Manually update the DHCW Figma design system

Information:

Since a recent update, Figma no longer allows you to use or reference published shared libraries across completely separate organisations or external user spaces. Therefore, separate corporate organisations or personal external spaces cannot link to each other's live, updating component libraries.

  1. Every so often, check DHCW Design System for updates.
  2. Save a local copy of the latest version of the Figma library.
  3. Reload it into your Figma workspace as a library.
  4. Open your design files, and use the swap libraries feature in Figma to replace all references to the outdated version of the DHCW Figma design system. You can only use 'swap libraries' with a paid Figma licence. If you do not have one, swap components individually instead.
