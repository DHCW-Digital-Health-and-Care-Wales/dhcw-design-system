Page templates

Updated in March 2026

Use page templates to create consistent layouts across Digital Health and Care Wales services.

Templates help you:

  • prototype and test pages quickly
  • create consistent user experiences across services
  • use familiar layouts and navigation patterns that meet user expectations

Page template structure

Templates show how design system components and patterns work together to create a page.

Top

Contains components that are common across the service, such as:

  • site header
  • skip links
  • site navigation

Main content

Contains the primary page content. Use the layout component to control page width and content structure.

  • bottom - for the site footer, which is anchored to the bottom of the browser window

Bottom

Contains the footer and supporting links, such as accessibility, privacy and cookie information.

Background colour

Page templates use the $nhswales-page-background-grey background colour. The British Dyslexia Association's style guide recommends dark text on a light, but not white, background.

This helps:

  • reduce visual glare
  • support users who prefer lower contrast backgrounds
  • make important components stand out, like warning callouts

Public-facing page templates

Public-facing templates are designed for patients, carers and members of the public.

They use top navigation and familiar content layouts to support browsing, finding information and accessing services.
