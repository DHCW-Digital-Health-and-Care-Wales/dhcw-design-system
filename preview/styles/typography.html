Typography

Updated in March 2026

Use font and typography styles to create clear, readable content and establish visual hierarchy in services.

Font

Roboto

Digital Health and Care Wales uses Roboto across its services.

Default to Arial if Roboto is not available.

font-family: "Roboto", Arial, sans-serif;

Headings

Use heading levels from <H1> to <H6> to create page structure. Heading levels help browsers, search engines and assistive technologies understand how content is organised. They also allow screen reader users to navigate content by moving between headings.

Use heading styles, like heading XL, to create visual hierarchy. The heading level and heading style should usually match, but page structure should always take priority.

You should:

  • follow heading levels in sequence
  • keep headings concise and descriptive
  • not skip heading levels
  • not choose a heading level based solely on its visual size

Accessibility

  • Use heading levels in the correct order to create a meaningful content structure and support navigation for screen reader users. This supports WCAG 2.2 Success Criterion 1.3.1: Info and Relationships (Level A).
  • Ensure text can be resized up to 200% without loss of content or functionality. This supports WCAG 2.2 Success Criterion 1.4.4: Resize Text (Level AA).
  • Maintain sufficient contrast between text and background colours to ensure content remains readable. This supports WCAG 2.2 Success Criterion 1.4.3: Contrast (Minimum) (Level AA).
  • Ensure text reflows correctly across screen sizes and zoom levels without requiring horizontal scrolling. This supports WCAG 2.2 Success Criterion 1.4.10: Reflow (Level AA).
